# Label font bundle

These files are the print font sources used by `tools/render_bottle_label.py`:

- `PinyonScript-Regular.ttf` - Pinyon Script Regular
- `CormorantGaramond-Regular.ttf` - Cormorant Garamond Regular (400)
- `Montserrat-Medium.ttf` - Montserrat Medium (500)

They match the Google Fonts families and weights declared by the invitation
website. Each family is distributed under the SIL Open Font License 1.1; the
corresponding license text is included alongside the font file.
